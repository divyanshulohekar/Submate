# Vault — Smart Subscription & Hidden-Expense Detector

> **"Discover first. Ask users to confirm."**  
> *Turn raw financial statements into actionable subscription intelligence.*

SubMate AI is a production-grade FinTech intelligence platform built for **PS-11 (Smart Subscription & Hidden-Expense Detector)**. It moves beyond passive, manual subscription trackers by automatically ingesting bank statements, normalizing noisy merchant identifiers, detecting recurring cadence with variance protection, discovering silent price hikes, and presenting structured evidence to the user for one-click confirmation.

---

## 1. Product Vision & Core Principle

**"Never automatically classify every recurring payment as a subscription."**

Repeating debits can represent contractual liabilities (rent, EMIs, insurance, SIPs, utility bills) rather than optional subscriptions. SubMate enforces category guardrails and generates high-confidence **Candidates** with transparent evidence:
- Repeat count and date intervals
- Interval variance (handling shifted billing dates)
- Amount stability and detected tariff hikes
- Cleaned canonical merchant aliases

Only when a user clicks **[Confirm Subscription]** does the candidate enter the active subscription ledger.

---

## 2. Key Features

- **Automated Statement Ingestion**: 7-step wizard supporting CSV, XLSX, and password-protected bank PDFs (decrypted client-side via PDF.js).
- **Merchant Alias Normalization**: Strips UPI, POS, NEFT, and payment gateway noise (`AMZN Mktp IN` → Amazon Prime, `NETFLIX.COM BANGALORE` → Netflix).
- **Shifted Billing Date Intelligence**: Recognizes monthly cadence even when bank debits fall on variable dates (e.g., 5th, 7th, 6th, 9th, 8th).
- **Price Change Detector**: Flags historical step-ups in recurring debits (e.g. Netflix increased from ₹499 to ₹649, adding ₹1,800/yr).
- **Candidate Confirmation Center (`/discover`)**: Evidence cards with confidence scores, interval statistics, and one-click confirmation.
- **Subscription X-Ray (`/xray`)**: Category concentration audits, highest-cost software drivers, and feature redundancy detection.
- **Renewal Calendar (`/calendar`)**: Interactive monthly forecasting calendar distinguishing confirmed renewals from estimated windows.
- **Savings Simulator (`/savings`)**: Deterministic interactive simulator calculating live monthly and annualized savings (₹1,535/mo → ₹18,420/yr).
- **Gemini-Powered Explanations**: Concise, plain-language summaries explaining why candidates were flagged and how to optimize tiers.
- **Integration Adapters (`/connections`)**: Working statement ingestion plus sandbox adapters for RBI Account Aggregator (Setu) and UPI AutoPay mandates.
- **Mobile-First PWA**: Responsive thumb-navigation, bottom sheets, floating action button, web manifest, and offline service worker.

## 4. Database Architecture & Schema

The production schema is located at `supabase/schema.sql` with full Row Level Security (RLS) policies:

1. `profiles`: User account, currency (INR default), timezone
2. `financial_connections`: Consent handles, sync status, and provider metadata
3. `transactions`: Canonical ledger with normalized merchant and recurrence confidence
4. `subscriptions`: Confirmed active commitments, billing cycles, and next renewal dates
5. `detection_candidates`: Review queue for recurring patterns awaiting confirmation
6. `notifications`: Renewal alerts, price spike warnings, and candidate notices
7. `ai_insights`: Structured AI summaries generated by Gemini
8. `savings_recommendations`: Deterministic optimization suggestions
9. `audit_logs`: Immutable trace of user actions and security events
10. `merchant_aliases`: Lookup catalog for raw bank string normalization

To apply this to your Supabase project:
1. Open your **Supabase Dashboard** → **SQL Editor**.
2. Run `supabase/schema.sql`.
3. Optionally run `supabase/seed.sql` to populate reference merchant patterns.

## 8. Security & Privacy Guarantees

- **No Banking Passwords**: SubMate strictly never requests or stores bank login credentials, UPI PINs, card PINs, or CVVs.
- **Client-Side PDF Decryption**: Password-protected statement decryption executes purely within the browser sandbox via PDF.js; passwords never touch server logs.
- **Data Minimization for AI**: Only structured recurrence parameters (merchant name, frequency, repeat count, delta percent) are sent to Gemini—never raw bank statements.
- **RLS Isolation**: Every database row is isolated to the authenticated user ID (`auth.uid() = user_id`).
